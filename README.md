A Step Into Wellness

A Step Into Wellness is a walking based VR game designed for elderly users.  
It includes small, simple tasks that encourage gentle movement and interaction to support overall wellness.

How to Run the Game on VR
1. Open the Wonderland Engine project file containing A Step Into Wellness.
2. Connect the VR headset to the computer running the game, then select the headset device inside the Wonderland Engine.
3. Run the project and it will open a web browser containing the game and display inside the VR headset.
4. Click the VR button at the bottom of the screen to enter the virtual world.
NOTE: When you click the VR button, the headset will prompt a spatial awareness setup. This allows the user to draw out their surrounding play area. The user must carefully define this space and ensure it is large enough to safely walk around while playing the game.

How to Play the Game
1. Read the instruction panel, then click Main Menu to enter the main menu.
2. Click on the scene you want to start playing in.
3. Walk around the environment until you are ready to begin your first task, then click the start task button.
4. Read the task instructions from the panel and walk around to find the task you need to complete.
5. Simulate completing the task when you find it, then click the task completion button to move to the next task panel.
6. Once all tasks are completed, the final task button will take you back to the main menu, where you can choose a different scene or replay the same scene.
